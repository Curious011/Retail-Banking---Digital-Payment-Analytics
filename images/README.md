# Dashboard Screenshots

To display interactive screenshots on the main repository `README.md`:

1. Open `Finance_Analytics_Dashboard.pbix` in Power BI Desktop.
2. Go to **View** > **Full Screen** (or press `F11`).
3. Take a screenshot of **Page 1 (Overview Analysis)** and save it as:
   `images/dashboard_overview.png`
4. Take a screenshot of **Page 2 (Transactions)** and save it as:
   `images/dashboard_transactions.png`

The main `README.md` is already pre-configured to automatically display these images once saved here!
